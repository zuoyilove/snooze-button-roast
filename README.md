One line roasting an alarm clock that rings at 6 AM on a Saturday: it acts like it has a shift to catch, so the roast congratulates it on being the only thing in the house with a job.

The joke lands on the twist — the clock is the employed one, not you — and the punchline pays off in the last few words. The program is deterministic: it writes the same single line to `/output/entry.txt` on every run and prints it to stdout.

## Run it

```sh
node main.ts
```
